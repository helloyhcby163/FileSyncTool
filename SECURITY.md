# Security Policy / 安全策略

## Supported Versions / 支持的版本

目前，只有最新发布的版本会获得安全更新。**由于安全风险，强烈建议不要使用 v7.6.0 至 v7.7.0 版本。**

Currently, only the latest release receives security updates. **Due to security risks, we strongly advise against using versions v7.6.0 to v7.7.0.**

| Version / 版本 | Supported / 支持状态 |
| ------- | ------------------ |
| >= 7.7.1 | :white_check_mark: |
| 7.6.0 - 7.7.0 | :x: (Deprecated / 已废弃) |
| < 7.6.0 | :x: |
