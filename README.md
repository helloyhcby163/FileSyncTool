\# FileSyncTool / 文件同步工具



一个专注 U 盘与文件夹同步的跨平台文件同步工具，注重性能与跨平台兼容。



\## 核心特性



\- \*\*性能优先\*\*：多线程扫描与复制、大文件分块传输、断点续传、块级寿命保护

\- \*\*跨平台\*\*：完整支持 Windows / macOS / Linux

\- \*\*U 盘优化\*\*：写入寿命保护、可移动磁盘检测、U 盘脱落处理

\- \*\*GUI 美观好用\*\*：基于 CustomTkinter，支持明暗主题

\- \*\*纯本地\*\*：无云服务依赖，所有数据在用户设备上
